# Portfólio de Gustavo Henrique

[Acesse o portfólio](https://www.gustavohenrique.dev.br/)

Projetos selecionados de desenvolvimento, dados e automação. A página apresenta o Synapse, os dashboards financeiros e a plataforma de recomendação de serviços. Inclui um simulador de retrabalho e contato para diagnóstico pelo WhatsApp.

## Desenvolvimento local

Abra `index.html` no navegador. O site usa HTML, CSS e JavaScript, com imagens e fonte hospedadas no próprio repositório.

Para servir a página com Python, execute `python -m http.server 4173` na raiz do repositório e acesse `http://localhost:4173`.
